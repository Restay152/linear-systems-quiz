# 线性系统 · 判断练习

三张课堂图片中的全部 17 道判断题，包含校订后的答案、解析与适用前提。

支持顺序练习、随机练习、知识点筛选、错题重练、收藏、答题总结与浏览器本地进度保存。

## 发布到 GitHub Pages

1. 在 GitHub 创建一个公开仓库，建议命名为 `linear-systems-quiz`。
2. 将本文件夹中的 `index.html`、`.nojekyll` 和 `README.md` 上传到仓库 `main` 分支的根目录。不要再套一层文件夹。
3. 打开仓库 **Settings → Pages**。
4. 在 **Build and deployment** 中选择 **Deploy from a branch**。
5. 选择 **main** 分支和 **/(root)** 文件夹，点击 **Save**。
6. 等待部署完成。使用 Pages 设置页显示的实际访问地址。

项目站点的地址通常为：

```text
https://你的GitHub用户名.github.io/linear-systems-quiz/
```

以上只是地址格式，不是已经部署的网站地址。

## 文件与部署

- `index.html`：完整单文件网页，样式、脚本和题库均已内嵌。
- `.nojekyll`：让 GitHub Pages 直接发布静态文件。
- 不需要安装依赖、运行构建命令、配置服务器或数据库。
- 更新时替换 `index.html` 并提交即可。
- 网页没有外部字体、框架或 CDN 依赖，项目仓库的子路径也能正常使用。

## 学习记录

记录保存在各自浏览器的 localStorage 中，不会上传到 GitHub。
从离线文件或其他域名迁移到 GitHub Pages 后，会开始一份新的浏览器记录；不同域名之间不自动同步。
